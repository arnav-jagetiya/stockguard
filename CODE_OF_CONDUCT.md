# Community Code of Conduct

## 1. Purpose & Values

STOCKGUARD is committed to providing a respectful, welcoming, and collaborative environment for all contributors, maintainers, and community members. We value open collaboration, thoughtful technical discussion, constructive feedback, and mutual respect across all project spaces, including issues, pull requests, and discussions.

## 2. Expected Standards of Conduct

Contributors and participants are expected to uphold the following positive standards:

- **Constructive Communication:** Engage in professional, empathetic, and evidence-grounded dialogue, focusing on code quality, architecture, and problem solving.
- **Respect for Differing Perspectives:** Welcome diverse technical viewpoints and experiences gracefully.
- **Graceful Collaboration:** Accept constructive criticism respectfully and collaborate toward maintainable, high-quality solutions.
- **Community Focus:** Prioritize what is best for the overall project, its security invariants, and the broader user community.

## 3. Unacceptable Behavior

The following behaviors are strictly prohibited within the STOCKGUARD project and its related communication channels:

- Harassment, intimidation, trolling, or derogatory commentary directed at individuals or groups.
- Personal attacks, insulting language, or discriminatory remarks regarding personal characteristics.
- Unwelcome sexual attention, remarks, or physical advances.
- Publishing private information of others (such as physical addresses, private email addresses, or phone numbers) without explicit consent.
- Malicious disruption of discussions, spamming, or bad-faith interactions.
- Encouraging or advocating for any of the above prohibited behaviors.

## 4. Maintainer Responsibilities

Project maintainers are responsible for clarifying and enforcing our standards of conduct. Maintainers have the right and responsibility to remove, edit, or reject comments, commits, code changes, issues, and other contributions that do not align with this Code of Conduct.

Maintainers will handle all reported concerns fairly, objectively, and in good faith, respecting the privacy of individuals reporting an issue.

## 5. Scope

This Code of Conduct applies within all official STOCKGUARD project spaces on GitHub (including code reviews, issues, discussions, and pull requests) and when representing the project in external public or community forums.

## 6. Reporting & Enforcement

If you experience or witness unacceptable behavior, please report the incident to the project maintainer:

- **Reporting Route:** Contact the project maintainer directly via GitHub (@arnav-jagetiya) or initiate a private discussion if permitted by repository settings.
- **Information to Include:** A description of the incident, relevant links, timestamps, and any context that assists in objective review.
- **Confidentiality:** All reports will be handled with appropriate discretion.

Maintainers may take fair and proportionate enforcement actions depending on the nature of the violation, including:
1. **Correction:** A private conversation providing clarification on expected standards.
2. **Warning:** A formal notice detailing the violation and consequences of continued misconduct.
3. **Temporary Restriction:** Temporary suspension from repository interactions (e.g., commenting or submitting contributions).
4. **Permanent Exclusion:** Permanent ban from participating in the repository and community spaces for severe or repeated violations.
